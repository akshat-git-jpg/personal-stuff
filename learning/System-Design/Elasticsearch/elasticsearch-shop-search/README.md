# Elasticsearch, explained with a shop search

Learning Elasticsearch by **looking at it**, not by running it.

No code. Concepts and pictures only.

Everything you need is in three places.

---

## 1. The diagrams

**[`diagrams/`](diagrams/)** — real Excalidraw files. Drag one onto
**https://excalidraw.com** and it opens. You can move parts and change them.
Doing that is a good way to check you understood.

Diagrams get made when you ask. The list here grows over time.

## 2. The interview answers

**[`INTERVIEW.md`](INTERVIEW.md)** — the 30-second spoken answer for each idea,
plus the follow-up an interviewer uses to check that you know it for real.

## 3. The map of what is left to learn

**[`CURRICULUM.md`](CURRICULUM.md)** — the ideas still to cover. Each one is
framed as a problem that breaks the shop. It does **not** give the answer.
Ask for one and you get the answer plus its diagram.

**[`NOTES.md`](NOTES.md)** — yours. One line per idea: the thing that
surprised you.

---

## How this works

You ask. I answer in plain words and draw the picture.

- **"visualise X"** → a new `.excalidraw` file in `diagrams/`
- **"explain X"** → plain answer, then a diagram if it helps
- **"cover X"** → the idea plus its interview section plus its diagram

Every diagram uses a real shop: many products, many filters, many users
searching at the same time. No toy one-product examples.
