The question

Scripted software tutorial videos. TTS voiceover, not live human voice. Team split: the tutorial maker knows the tool; the video editor is strong at editing but does not know the tool. Which of the three workflows (A, B, C) fits best?

Workflow A - Record screen free, editor syncs

Tutorial maker records raw section-wise clips with no attempt to match TTS timing. Editor syncs everything on the timeline.

Pros

  • Fastest recording. No TTS in the ears.
  • Section-wise files = small sync problems, not one big one.
  • Editor uses their strengths (cut, motion graphics, b-roll).
  • Re-shoots are cheap (one section, not the whole video).

Cons

  • Editor can only trim well - stretching short clips looks laggy.
  • Needs a rule: record slower than the VO, leave 1-2s pauses between actions.
  • Screen action can feel disconnected from the words if the recorder rushes.

Workflow B - Record screen in sync with TTS

Tutorial maker records the screen with the TTS playing, matching action to voice.

Pros

  • Screen action lands on the right words.
  • Editor mostly polishes - almost no sync work.
  • Feels natural. Actions match the pace of the voice.

Cons

  • Hard for a human. Recorder either rushes clicks or waits awkwardly.
  • Any script rewrite = re-record that section from scratch.
  • Slower recording. High cognitive load.

Workflow C - Editor records the screen

Editor understands the script and records the screen themselves.

Pros

  • Total control over sync in one head.
  • No handoff friction between roles.

Cons

  • Editor does not know the tool. Wrong clicks, wrong menus, wrong outcomes.
  • Not viable for real software tutorials.

Notes

Workflow A and Workflow B are pretty similar. The only difference is who is responsible for syncing the voiceover with the screen recording.

  • In Workflow A, it is mostly relied on the video editor to sync the voiceover and screen recording.
  • In Workflow B, it is mostly relied on the tutorial maker.

Basically in Workflow A, the first role is mainly a script writer. In Workflow B, the first role is mainly a tutorial maker.
