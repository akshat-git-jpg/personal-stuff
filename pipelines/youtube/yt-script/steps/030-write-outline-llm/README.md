## What happens

Read `OUTLINE-INSTRUCTIONS.md` in full and follow it exactly. Write
`videos/<key>/outline.md`.

## The one rule that matters

**One line per section. Never two.** The moment a section gets a paragraph, this
has stopped being an outline and started being the script plan.

No spoken copy. No `SAY`/`SHOW`/`EDIT`/`FACTS`. No verdicts, blockquotes or
tables. Those are all script-plan forms and putting them here means the two
documents will drift.

## Why it is separate from the script plan

A wrong running order costs one page here. It costs a 25-beat rewrite at 050.
