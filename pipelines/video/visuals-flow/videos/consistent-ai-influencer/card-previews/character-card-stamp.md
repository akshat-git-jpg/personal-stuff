# Look preview — `enacted/character-card-stamp`

Owner rule 2026-07-31 / 2026-08-01: the look gets previewed before any card code
exists. Run these two in Google Gemini/Flow. The approved frames become the
visual contract the card is built to match.

Cue: **c20**, body @ ~562.9s — *"no matter how different the scenario is in here,
the same face is applied"*.

What it does: one portrait card holds the anchor face; each beat stamps a
duplicate of it into a new scenario frame, and every duplicate keeps the
identical face — so consistency is shown rather than claimed. This is the
concept's through-line (`the-character-card`), the same object the intro film
opens on.

Two moments: the card alone before any stamp, and the card after both stamps.

## Moment 1 — the anchor card, before any stamp

```
Flat 2D motion-graphics still frame, 16:9, 1920x1080, from a premium dark
tech explainer video.

TEXT RULE: the ONLY text anywhere in the image is: "One Face, Every Scenario"
and "ANCHOR".
No headline, no tagline, no subtitle, no watermark, no other words at all.

Background: near-black warm brown (#0d0906), one very soft dim orange glow

COMPOSITION: a single portrait card stands alone in the centre of the frame,
slightly left of true centre, occupying roughly a third of the frame height.

letterspaced wide. The title "One Face, Every Scenario" runs across the upper
third, white, with the word "One" in orange #fb923c. The right half of the
frame is deliberately empty dark space — the room the duplicates will land in.

Style: flat design, matte surfaces, crisp vector edges, single accent
color (white + orange #fb923c), Swiss/Apple-keynote minimalism.
NO 3D extrusion, NO lens flares, NO sparkles, NO light streaks,
NO gradients on text, NO photographic realism.
```
