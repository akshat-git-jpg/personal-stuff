What changed. v1 was illustrated scenes — an engine buried in cables, a maze, a peeled poster. Those are pictures you have to read. v2 replaced them with text, which put paragraphs on screen. Both were wrong.

v3 is movement. A clock that spins. A lock that clicks open. A ball that rolls and hits a wall. A tick that draws itself. Everyone already knows these — there is no second meaning to work out, and each one starts on the word it belongs to.
