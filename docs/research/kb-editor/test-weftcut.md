## Surprises

- **Overlay WebMs lose alpha** in preview (black box) and in proxies. Transparent graphics work only as Motifs, which is fine for HyperFrames cards but a gap for any alpha video (ProRes 4444 or VP9 alpha avatars).
- **Original-media playback drops a lot of frames**: 79% in the dense section on the 3K VFR file. With proxies on it is clean, but proxies are off by default (`prefer_proxies: false`).
- **The MCP server has no playhead or selection read.** The session view and `read_project` cover project state, history, tacks and markers, but not where the user is or what they selected. Requirement 3 needs that added (it should be small, given T8).
- **Puppeteer and occlusion:** when the window was covered, Chromium stopped rAF and playback stalled after about 3.5 s. I relaunched with `--disable-backgrounding-occluded-windows`. A real user with the window in front would not hit this.
- **Telemetry:** none found. On macOS the auto-updater is disabled in code (`createUpdates(… process.platform !== 'darwin' …)`), and the only network fetch is the opt-in model download.
- Import makes a **full copy** of every media file into the project. That is portable, but it doubles disk use for 4K screen recordings.
- About 440k LOC with half of it tests, 119 ADRs, from essentially one contributor in 5 months. The code is clearly agent-written and agent-readable. That makes it easy to own, and also means the upstream bus factor is 1.

## Verdict: is this a good base to fork and own for years?

**Yes. It is the strongest base tested so far**, with clear work items.
- **Measured:** the agent surface is excellent (121 tools, ms-level, precise refusals, undo, checkpoints). HyperFrames cards run as live, transparent, seekable layers with a 31-line adapter. Export matches preview geometry. A real change built and worked in under 10 minutes, and its test suite passed.
- **Gaps:**
  1. Playhead/selection over MCP.
  2. Alpha video.
  3. Proxies on by default for heavy screen recordings.
  4. A first-class freeze frame.
  5. Motifs travelling inside the project folder.
  6. The embedded Claude terminal pane.
  7. A transcription engine, or Claude-side Whisper.
- **Inferred:** each gap looks like days of agent work, not a rewrite. The ADR-heavy, test-heavy codebase lowers that risk. The real risks are upstream churn from a single maintainer and the size of the code to keep in sync if we track upstream. Windows was not tested here; CI claims Win/Mac/Linux and a win-x64 installer ships.
